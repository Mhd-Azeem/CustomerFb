സ്വകാര്യതാ നയം

പുതുക്കിയത് 2026-11-27

ഞങ്ങൾ ശേഖരിക്കുന്ന വിവരങ്ങൾ

ഈ സൈറ്റിൽ അപേക്ഷാ ഫോമോ അക്കൗണ്ടോ ഇല്ല. WhatsApp വഴി സന്ദേശമയച്ചാൽ WhatsApp ഞങ്ങൾക്ക് കാണിക്കുന്ന ഫോൺ നമ്പറോ പ്രൊഫൈൽ വിവരങ്ങളോ, നിങ്ങളുടെ സന്ദേശം, നിങ്ങൾ അയയ്ക്കുന്ന വിവരങ്ങളും അനുബന്ധ ഫയലുകളും എന്നിവ ലഭിക്കും. ആദ്യ സന്ദേശത്തിൽ പാസ്‌പോർട്ട് നമ്പർ, തിരിച്ചറിയൽ രേഖകൾ, മെഡിക്കൽ വിവരങ്ങൾ, ബാങ്ക് വിവരങ്ങൾ എന്നിവ ഉൾപ്പെടുത്തരുത്.

വിവരങ്ങളുടെ ഉപയോഗം

അന്വേഷണത്തിന് മറുപടി നൽകാനും അടുത്ത ഘട്ടങ്ങൾ വിശദീകരിക്കാനും, നിങ്ങൾക്ക് മുന്നോട്ട് പോകാൻ താൽപര്യമുണ്ടെങ്കിൽ ബന്ധപ്പെട്ട ലൈസൻസുള്ള തൊഴിൽ ഏജൻസിയിലേക്ക് അന്വേഷണം കൈമാറാനും വിവരങ്ങൾ ഉപയോഗിക്കുന്നു. രേഖകൾ കൈമാറുന്നതിന് മുമ്പ് ഏത് ഏജൻസിക്കാണ് വിവരങ്ങൾ ലഭിക്കുകയെന്നും എന്തൊക്കെ ആവശ്യമാണെന്നും ചോദിക്കുക. ഏജൻസി സ്വന്തം റിക്രൂട്ട്മെന്റ് രേഖകളും സ്വകാര്യതാ നടപടികളും കൈകാര്യം ചെയ്യുന്നു.

WhatsApp-ഉം സൈറ്റ് ഹോസ്റ്റിംഗും

ബന്ധപ്പെടാനുള്ള ലിങ്ക് WhatsApp-ൽ ഒരു കരട് സന്ദേശം തുറക്കുന്നു. അയയ്ക്കുന്നതിന് മുമ്പ് അത് പരിശോധിക്കാം. WhatsApp സ്വന്തം സ്വകാര്യതാ നയം അനുസരിച്ചാണ് അത് കൈകാര്യം ചെയ്യുന്നത്. ഈ സൈറ്റ് ഹോസ്റ്റ് ചെയ്യുന്ന GitHub Pages സേവനം നൽകുന്നതിനും സംരക്ഷിക്കുന്നതിനും IP വിലാസം ഉൾപ്പെടെയുള്ള സാങ്കേതിക അഭ്യർത്ഥനാ വിവരങ്ങൾ കൈകാര്യം ചെയ്തേക്കാം. നിങ്ങളുടെ അന്വേഷണ വിവരങ്ങൾ ഈ സൈറ്റ് ബ്രൗസറിൽ സൂക്ഷിക്കുന്നില്ല.

ഭാഷാ മുൻഗണന നിങ്ങളുടെ ഉപകരണത്തിൽ സൂക്ഷിച്ചേക്കാം. രേഖാപട്ടികയിൽ നിങ്ങൾ അടയാളപ്പെടുത്തിയ വിവരങ്ങൾ ഞങ്ങൾക്ക് അയയ്ക്കുന്നില്ല. WhatsApp, GitHub, നിങ്ങൾ ബന്ധപ്പെടുന്ന ഏജൻസി എന്നിവയ്ക്ക് അവരുടെ നയങ്ങൾ പ്രകാരം മറ്റ് രാജ്യങ്ങളിൽ വിവരങ്ങൾ കൈകാര്യം ചെയ്യാം.

വിവരങ്ങൾ സൂക്ഷിക്കുന്നതും സുരക്ഷയും

തുടർനടപടികൾക്കും ബാധകമായ ബാധ്യതകൾക്കും അനുസരിച്ചാണ് അന്വേഷണ സന്ദേശങ്ങൾ സൂക്ഷിക്കുന്ന കാലയളവ്. നിശ്ചിത കാലയളവ് പ്രസിദ്ധീകരിച്ചിട്ടില്ല. ആദ്യ ചാറ്റിൽ രഹസ്യ രേഖകൾ അയയ്ക്കരുത്. അയയ്ക്കേണ്ടതുണ്ടെങ്കിൽ, സ്വീകരിക്കുന്നവരെയും സുരക്ഷിതമായ സമർപ്പണ മാർഗത്തെയും ലൈസൻസുള്ള ഏജൻസിയുമായി സ്ഥിരീകരിക്കുക.

നിങ്ങളുടെ അഭ്യർത്ഥനകൾ

നിങ്ങൾ നൽകിയ വിവരങ്ങളെക്കുറിച്ച് ചോദിക്കാനും അവ ലഭ്യമാക്കാനോ തിരുത്താനോ നീക്കം ചെയ്യാനോ താഴെയുള്ള WhatsApp നമ്പർ വഴി അഭ്യർത്ഥിക്കാം. ബാധകമായ നിയമവും രേഖകൾ സൂക്ഷിക്കാനുള്ള ബാധ്യതകളും അനുസരിച്ച് നൽകാനോ നീക്കം ചെയ്യാനോ കഴിയുന്ന വിവരങ്ങൾക്ക് പരിധിയുണ്ടാകാം. ഏജൻസിയുടെ കൈവശമുള്ള വിവരങ്ങൾക്ക് ആ ഏജൻസിയെ നേരിട്ട് ബന്ധപ്പെടാം.

നയത്തിലെ മാറ്റങ്ങൾ

മാറ്റങ്ങൾ ഇവിടെ പ്രസിദ്ധീകരിക്കും. ഏറ്റവും പുതിയ പതിപ്പിന്റെ തീയതി മുകളിൽ കാണാം.

സ്വകാര്യത, തിരുത്തൽ, വിവരങ്ങൾ നീക്കം ചെയ്യൽ എന്നിവ സംബന്ധിച്ച അന്വേഷണങ്ങൾ
